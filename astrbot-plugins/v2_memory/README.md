# V2 群聊记忆

该插件将群记忆管理接入 AstrBot 原生插件页。只有真实 Dashboard Owner 可以查看或修改数据。管理 API 使用 AstrBot 插件页桥接，不另开服务。

记忆服务仅在 `v2_dsh_router` 已初始化且未关闭后启动，并绑定到 Router；卸载或关闭时会先撤销绑定并等待本插件的模型调用和存储操作结束，再释放群卷。

每群的记忆、修订、来源指针、成功游标和运行记录保存于其工作区 `.v2-memory/state.sqlite3`，不覆盖已有 `memory/`。AstrBot 的 `plugin_data/v2_memory/groups.json` 只保存首批启用群身份。群卷备份包含实际记忆库；清理记忆保留整理游标，避免重新导入旧消息。

整理使用 Journal、当前 `persona.md` 与必要的已有记忆，复用 DSH 当前模型完成无 Session、无工具调用。后台按新增群友消息数或最长等待触发，门槛与等待在本页持久配置；Bot消息保留为内容但不计数。旧全局及内置每日记忆任务已退役。默认 `/new` 补齐尾段后才重置；失败保留上下文和未完成范围，`/new skip_mem` 或 `/new 跳过记忆` 可显式重置，记忆游标不前移。

后台失败或取消后暂停，新增消息和重启不会自动重试。页面可显式重试未完成范围，或由手动整理成功覆盖后解除。已完成批次保持。Agent停用与插件关闭会排空记忆调用并保留剩余范围。

新陈述包含来源 ID 和原文引句，程序校验并绑定真实发言者；原文出处正确不保证模型解释正确。旧数据保留为legacy，仅部分补充引用的旧记忆为partial；手工编辑标为待核对，历史证据保存在修订快照中。

页面支持按群启停、浏览与搜索、查看记忆和来源、编辑记忆、导出 JSON、确认清理，以及查看最近整理状态、耗时和可用的模型用量。来源核实通过当前群的真实记忆 ID 进行定点查询；页面不提供任意 Journal 搜索入口。

检索一次完成精确和中文二元字符近似匹配，不额外调用模型或自动反复改写查询；不声称等价于向量语义检索。权重1–5仅表达长期显著性，没有置信度门槛或按时间自动删除。未识别媒体只保留可证元数据。安装时将插件实体目录放在 `data/plugins/` 内，以便原生插件页发现。
