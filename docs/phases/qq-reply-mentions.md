# QQ 回复必须提及对方

> 此为上一轮已验方案；用户随后明确改由模型选择原生提及和引用，普通交流契约以[当前阶段](qq-model-messaging.md)为准。

用户要求 Bot 回复消息时必须 @ 对方，并询问模型能否自主决定 @ Owner。当前实现范围为：

- QQ 群聊的普通文字、模型工具文字、每次最终回复、V2 命令和原生结果链回复均包含原生 At，目标绑定当前入站发言人；私聊保持直接回复。
- 轮次异常及发送失败保留现有 Owner 核验与提及，再提及发言人；同一人只出现一次。
- 文件使用原生文件发送，群文件另带一条 @ 发言人的配套文字；原生长结果包装为合并转发后亦补外层 @ 提示。
- 实现复用 AstrBot 消息组件和结果装饰 hook，直接发送在 V2 自身入口处理，不改上游、不改权限或会话路由。
- 模型当前只有纯文本发送参数，没有选择原生 @ 目标的工具。本轮不预先实现“模型向 Owner 求助”。未来可由模型决定触发时机、由宿主解析配置并核验当前群 Owner 身份；单加一句指南不构成工具能力。

验证与运行版本见[验证及部署记录](../qq-reply-mentions-validation.md)。
