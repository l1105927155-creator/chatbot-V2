## 当前要求

1. 已准入群中的真实纯 @Bot（允许附带空白文本）也唤醒 DSH，由当前人格简短自然回应呼唤。没有具体任务时不臆造任务。不把纯媒体、纯引用、@其他人、@全体、昵称文字或未准入群扩展为新唤醒入口。
2. 当请求明确要求等待，或 DSH 预计操作会让用户等待数秒以上（包括单条命令自身等待）时，先通过现有 scoped `qq_send_origin` 发送一次简短、具体的等候说明，再继续完成任务。普通交流和快速查询不例行发送，不逐工具播报，最终回复不重复说明。失败或发送回执不确定时不自动重发。时机由模型判断，Router 不增加自然语言分类或定时播报器。
3. QQ 回复采用自然纯文本，用换行、编号与原始 URL；避免 Markdown 标题、强调、表格、代码排版标记与 Markdown 链接。代码正文和技术标识保持原义，不对生成文本做可能损坏代码的正则剥离。既有 AstrBot 文本消息段负责传输，不新增渲染器。原生网页工具默认的 Markdown 引用格式通过当前 Agent 的 scoped assembly 改成裸 URL，其余来源核验与不可信数据说明保留。
