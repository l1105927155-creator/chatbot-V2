# QQ 交流表达与模型消息边界

观察状态：已完成48轮隔离真实Flash比较，链路核对与表达判断分开。少量示范有帮助，但未达到稳定自然交流目标；不替换正式指南，不标记为已部署。详见[评估记录](../chat-expression-evaluation.md)。

## 阶段目标

用户授权以自然聊天室交流为目标：闲聊接话自然，观点讨论有依据且能按追问展开，工具结果按信息需要交代；内容深度和QQ消息边界由模型决定，不统一规定每次一两句，不按字符数或空行机械拆分。

## 实施路线

先在隔离副本中比较“简短交流原则”与“同原则加少量压缩示范”，使用同一固定Flash模型和多轮情景。优先沿用原生MCP的qq_send_origin发送前段、final发送尾段；Profile与工具说明保持一致。常驻交流原则、工具使用说明及Persona保持职责分离；较丰富的多轮情景留在离线验收中。

程序保留权限、发送生命周期、失败处理和canonical观察，按模型选择的消息边界发送。去掉600字符自动分组对正常final的改写。检查ACP工具循环中的文本采集，避免把中途叙述混进最终尾段而重复发送。不引入新平台或修改上游core。

## 完成标准

- 配对真实模型多轮验证覆盖闲聊、观点与异议、要求展开、实际工具的短结果及详细交付、重置说明，并有未用于示范的迁移情景。
- 指南实际加载、模型工具调用、QQ所有出站、平台回执及Journal相互关联；链路通过与表达人工判断分别报告，失败样本保留。
- 模型能依据上下文调整交流深度，选择具有交流作用的消息边界；不能把回复短或消息多本身算通过。
- 最小化常驻示范；记录A/B选择依据与上下文成本，说明小样本的实际保证范围。
- 聚焦与原生合同、失败/取消/重置回归、完整工程门通过；正式部署前受控备份并核对原会话及Journal。真实QQ客户端体验另行标明。
