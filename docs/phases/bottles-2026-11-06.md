# 漂流瓶

日期：2026-11-06
状态：已部署沙箱与生产测试群 1055300305；真实 QQ 待验收

## 范围

新增独立 AstrBot 插件 `v2_bottles`，第一版只支持文本漂流瓶：

- 群成员向 Bot 投放非匿名或匿名漂流瓶；
- 任何群成员随机捡取公共池中的漂流瓶，拾取不删除；
- 查询规则和当前总量；
- Owner 后台查看投放记录，包括匿名瓶的真实来源；可编辑提示文本，
  可勾选或全选本页记录并删除选中项。

不实现图片、视频、文件、限流、过期或指定编号检索。

## 已确认规则

- `@Bot 捡`：整条消息精确匹配，随机捡一个；拾取不修改、不删除记录。
- `@Bot 漂流瓶`：整条消息精确匹配，返回合并转发；第一行是当前总量。
- `@Bot 扔 内容`：命令词 `扔` 后必须有一个空格才命中；内容为非匿名投放。
- `@Bot 偷偷扔 内容`：命令词 `偷偷扔` 后必须有一个空格才命中；内容为匿名投放。
- `@Bot 扔了一只猫`、`@Bot 扔：一只猫`、`@Bot 偷偷扔了一只猫`、`@Bot 扔`、
  `@Bot 扔 ` 均不命中，按普通聊天交给 DSH。
- 投放命令携带图片、文件等媒体时回复“暂不支持图片”，不存入；
  文本仅为 `扔`/`偷偷扔` 且带媒体时同样进入媒体拒绝，不再交给 DSH。
- 非匿名瓶公开显示 `群号 - 昵称 - QQ`；匿名瓶公开只显示“匿名漂流瓶”，
  数据库始终保留真实群号、QQ 和昵称供后台核查。
- 仅群聊生效，私聊不接入。
- 不设过期；满 1000 条或占用 1GB 后停止存入并提示；Owner 可在后台删除
  选中记录以释放容量。

## 数据与上限

SQLite：`data/plugin_data/v2_bottles/bottles.sqlite3`

字段：`id`、`content`、`group_id`、`sender_qq`、`sender_name`、
`anonymous`、`created_at`（真实投放 Unix 秒）、`created_at_text`
（可编辑的显示日期）。

配置默认值：

- `max_bottles`：1000 条；
- `max_chars`：初始默认 200 字；运行时可在插件页“运行设置”修改，
  范围 1–10000，保存即时生效；
- `max_disk_mb`：1024 MB，按数据库、WAL 和 SHM 文件实际大小估算；
- `enabled_groups`：启用漂流瓶的群号列表，默认空。未列出的群不响应漂流瓶
  命令，继续按普通聊天交给 DSH；试点只填 `1055300305`。

两个上限在 `BEGIN IMMEDIATE` 写事务内检查，避免并发超限。

## 命令接入

固定版 AstrBot 的 `CommandFilter` 只匹配 `扔` 或 `扔 内容`，无法表达
“命令词后带空格才命中、否则交给 DSH”的规则，因此使用自定义
`BottleCommandFilter`：

- 仅 `aiocqhttp` 群聊；
- 首个有效消息段必须是真实 @本 Bot；
- 整条文本必须命中 `捡`、`漂流瓶`、`扔 内容` 或 `偷偷扔 内容`；
- 命中后设置 `v2_deterministic_handled`，让 router 不再唤醒 DSH。

未命中的消息不设置标记，继续按普通聊天交给 DSH。

## 后台

插件页：`/#/plugin-page/v2_bottles/bottles`

API：`POST /v2_bottles/api`

- `status`：总数、条数上限、字数上限、存储占用与上限；
- `list`：最近投放记录，可按群号/QQ 筛选，匿名瓶显示真实来源；
- 仅 Dashboard Owner 可访问；
- 记录不可修改或导出；Owner 可多选/全选本页并删除选中记录。

## 插件页 bridge 初始化修复（2026-11-06）

现象：进入插件页时出现“页面接口尚未就绪，请从 AstrBot 控制台重新打开。”

原因：AstrBot 在返回插件页 HTML 时，把
`/api/plugin/page/bridge-sdk.js` 注入到 `</body>` 前；原页面使用内联
