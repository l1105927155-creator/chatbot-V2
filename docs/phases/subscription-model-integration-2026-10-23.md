# ChatGPT 订阅模型接入 Bot

用户授权在确认可行后补齐 Web 订阅模型到 Bot 的可选目录与调用链路。

固定 DSH 0.2.0-rc.1 和订阅插件 3.1.5；不修改上游 core。Web 保留完整插件，通过原生适配器导出实际账号可见模型的非敏感描述；Bot 使用原生 PiAiAdapter 和 OAuth provider，仅复用账号 vault，不复制 token，不加载图片、连接器、远控或 Codex 子任务执行入口。QQ 正常收发、会话和工具权限保持原有路径。

涉及目录导出、专用订阅适配器、三个 Bot profile 和共享目录发布。动态目录更新独立于 YAML 配置更新，并保留现有模型选择与思考设置。

验收包括原生目录增删、账号切换/退出与刷新锁、实际 ACP 列举/切换/请求、工具权限和会话保留。部署前停写备份；实际验证记录另附。未经验证不宣称可用或上线。

已部署并完成 Owner 与四个开放群聊验收；普通非 Owner 私聊按用户明确说明不在业务范围。验证与限制见[记录](../subscription-model-integration-validation-2026-10-23.md)。
