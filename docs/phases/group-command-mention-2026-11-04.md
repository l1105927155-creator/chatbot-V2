# 群命令要求 @Bot

用户要求 QQ 群内所有命令先 @本 Bot，私聊无需 @。固定 AstrBot 的唤醒检查会把 `/` 前缀、@全体及回复 Bot 当作命令唤醒；普通 DSH 路由已有独立真实 @/回复检查，但原生命令未受其约束。

在现有 Router 插件生命周期内，给已注册和后加载的 AstrBot `CommandFilter`、`CommandGroupFilter` handler 前置过滤器。QQ 群消息的首个非空白消息段必须是真实 @本 Bot；不接受文本昵称、@他人、@全体、回复或命令后补 @。其他平台、QQ 私聊保留原生命令行为。过滤器在命令参数及权限检查之前运行，避免无 @ 时产生参数错误或权限回复；被动消息观察及链接识别不属于命令，保持原有行为。卸载 Router 时恢复原过滤器列表。
