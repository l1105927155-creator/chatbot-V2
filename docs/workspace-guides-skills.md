# 群工作区的维护入口

群成员日常只需维护本群的两份入口文件：

| 沙箱内路径 | 职责 | 加载方式 |
| --- | --- | --- |
| `/workspace/persona.md` | 人格、语气、交流偏好 | 每次模型请求加载，完整替代共享人格 |
| `/workspace/AGENTS.md` | 群约定、协作方式、资料和能力索引 | 每次模型请求加载 |
| `/workspace/skills/<name>/SKILL.md` | 一类任务的具体流程 | 先发现名称和摘要，需要时通过 `skill` 读取正文 |
| `/workspace/memory/` | 由群自行维护的持久资料 | 按 AGENTS 中的索引和当前任务需要读取 |

可直接在群中要求 Bot 修改人格或约定。两个已准入群分别使用独立卷；命令内均叫 `/workspace`，宿主实际路径可通过 `group_volume.paths()` 从平台、Bot、群号计算。不需要寻找或修改跨群公共指南。

首次初始化仅创建缺失的 AGENTS、persona 基础模板；已有文件不覆盖。模板在 `dsh/templates/group/`，后续修改模板仅影响尚未初始化的新群。主动删除已初始化群的指南会撤下对应内容，重启不会重新生成。空白指南也表示不注入；不安全或无法读取的文件会告警并撤下，不保留隐藏旧版本。

修改在下一次模型请求生效，也包括同一轮工具调用后的请求。已经发出的模型请求和已进入历史的旧正文不会被倒改；需要清除当前对话上下文可执行 `/new`，人格、记忆、Skill 文件继续保留。群 `/v2agent persona` 提示改用本群文件，私聊保留原有选择机制。

Skill 发现的优先级为：**本群 `skills/` → 共享 `dsh/skills/`**。同名使用本群版本；删除局部版本后重新发现共享版本。其他群的局部 Skill 不参与发现。全局可发现不意味着额外工具权限，工具仍由执行域控制。

`skill-authoring` 指导 Bot 在完成有探索成本且以后可重复的工作后，主动整理经过验证的步骤，再检查实际发现与加载；修改后简短告知成员。它使用已有文件和原生 Skill 能力，不增加每轮后台复盘。是否值得沉淀仍由模型判断，不承诺每次任务都会生成 Skill。

群文件通过验证群卷、逐级不跟随链接的只读适配器进入指南/Skill 系统。普通成员不能借助文件路径获得宿主读取或跨群发现能力。删除、覆盖等影响共享内容的操作应先提醒，优先采用可恢复方式。

完整边界和参考见[实施阶段](phases/workspace-guides-skills-2026-10-20.md)。本轮只补齐群级入口；非 Owner 私聊仍是 safe-chat，没有据此开放工作区写入。
