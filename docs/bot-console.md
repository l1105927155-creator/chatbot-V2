# V2 控制台使用

通过 AstrBot 原来的管理员账号登录，打开「V2 会话设置与工作区控制台」插件页面。页面地址为 `/#/plugin-page/v2_console/console`；使用现有 SSH 转发时可在 Windows 浏览器访问，文件实际读写在 Linux 服务端。

- **默认设置**：选择默认模型、启用状态和初始编辑者，保存后用于新会话。已有会话独立保存；会话字段旁的「恢复默认」填入最新默认值，再保存生效。首次上线不猜默认模型/启用状态，须先配置才能添加新群。
- **Workspace 模板**：内置六类人格：傲娇-嘴硬心软、病娇-极端深情、三无-冷淡寡言、天然呆-天真迷糊、元气-活泼热情、腹黑-外善内谋。每套含对应 `persona.md` 和基础 `AGENTS.md`，也可创建自己的模板。新版首次运行会导入或迁移一次；旧版未改动、未使用的多余预设从列表注销，已编辑或仍被群引用的模板保留。接入新群时选一套，仅创建时复制，不覆盖已有群的工作区。
- **会话**：按群号或 Owner 私聊选择；成员白名单只授予本群工作区修改权限。旧 `Owner.json` 不用于鉴权，已有群的编辑者需由你在后台设置。所有成员仍可接收附件到专用目录。
- **工作区文件**：支持目录、新建、文本编辑、重命名、删除、上传/下载。群只能访问自己的工作区，Owner 私聊显示已配置的主机工作目录。保存冲突时重新打开核对；指南和人格按现有热加载生效，应用代码保存不保证应用已重载。
- **导出会话目录**：选中会话，点击「下载」右侧的「导出会话目录」，下载 `<会话ID>-workspace.zip`（群聊使用群号，私聊使用用户号）。ZIP 从工作区根目录打包，保留普通文件、空目录、中文和隐藏文件；不跟随符号链接，不打包硬链接和特殊文件。导出的是服务器已保存内容，不包含编辑器未保存修改，也不包含存放在工作区外的会话设置。
- **禁用/启用**：仅停当前会话 Agent，并取消任务；Journal 和平台功能保留。启用本身不调用模型，等待新消息唤醒，禁用期间近期消息只作为背景。
- **上下文**：「立即压缩」调用原生压缩，可能产生摘要模型费用，安全范围不足时会明确显示未压缩；「新建上下文」保留工作区和 Journal。
- **重启**：重启整个 `chatbot-v2-agent.service`，等待新 PID、核心与 QQ 连接就绪。独立 DSH Web 保持运行；Bot 停机时本插件页面也暂不可用。

共享模型的凭据与目录继续在 DSH Web 管理。群应用写操作后续逐项适配，未适配操作按普通成员只读边界处理。

恢复范围由程序统一管理，当前最多补入100条、32KiB UTF-8输入，不新增控制台设置；该限制不清除禁用前已有上下文。后续预算校准与压缩信息损失验证属于持续工程工作，不再作为后台待确认弹窗；控制台提供机制不等于模型判断和指南遵循已得到保证。验证和剩余 `TODO(待确认)` 见[验证记录](bot-console-validation-2026-10-21.md)。

群应用的数据维护与工作区编辑权限分开：已通过app.json开放的业务操作使用group_app，只能写该应用的data目录；普通成员聊天可以触发Bot自主记分。代码、指南与规则编辑仍按当前请求者的编辑权限核验。好感应用已适配，详见[应用操作与超时](group-app-timeouts-validation-2026-10-22.md)。

内置人格预设源文件位于 `dsh/templates/workspace-presets/`；运行时通过私有模板目录和控制台元数据注册，非每次启动强制覆盖。新群可在“添加群”时选择。已有群想更换人格，应在对应群工作区自行编辑 `persona.md`，而不是修改模板后期待历史工作区自动同步。修改群人格不会改变该群的权限、模型或已有记忆。

v2 迁移只注销仍为默认内容且未被任何群引用的旧预设元数据；旧文件会保留，用户自定义模板不受影响。新增/替换预设不改变已有群的正在使用的人格。
