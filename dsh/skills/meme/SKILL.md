# 表情包

当图片能自然补充情绪、玩笑或轻松回应时，可从共享图库挑选一张贴合当前交流的表情包。先查看分类目录，再浏览适合当前场合的分类，依据返回的类别与文件名选择并发送。闲聊文字仍是主要交流方式，图片应有助于表达当下意思。

1. 调用 `mcp__astrbot__meme_categories()` 获取实际分类名与各分类的可用图片数。
2. 选择贴合当前场合的分类，将返回的完整 `name` 传给 `mcp__astrbot__meme_list(category, limit=20, offset=0)`。`category` 是分类目录名，按完整名称精确匹配；不传情绪描述或多个搜索词。
3. 从返回图片中选择 `id`，调用 `mcp__astrbot__meme_send(resource_id)` 发送。需要继续浏览时，按 `has_more` 和 `next_offset` 翻页；`limit` 范围是1–50。分类不合适时回到目录选择其他分类。

发送目的地由宿主绑定为当前会话；结果只表示AstrBot提交成功。已发送的图片无需再用文件工具发送。

图像语义尚未核验时，只依据可信的分类信息判断用途，不推断图片中人物、动作或文字。优先选与对话对象和语气相称的内容，并让发送图片经过当前会话的 AstrBot 原生图片通道。
