# 表情包

当图片能自然补充情绪、玩笑或轻松回应时，可从共享图库挑选一张贴合当前交流的表情包。先按交流场景或分类搜索，再依据返回的类别与文件名选择并发送。闲聊文字仍是主要交流方式，图片应有助于表达当下意思。

用 `mcp__astrbot__meme_list(query, limit)` 搜索，选取返回的 `id`，再交给 `mcp__astrbot__meme_send(resource_id)`。发送目的地由宿主绑定为当前会话；结果只表示AstrBot提交成功。已发送的图片无需再用文件工具发送。

图像语义尚未核验时，只依据可信的分类信息判断用途，不推断图片中人物、动作或文字。优先选与对话对象和语气相称的内容，并让发送图片经过当前会话的 AstrBot 原生图片通道。
