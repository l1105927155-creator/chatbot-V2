# 小游戏与 2048

用于本机小游戏、2048 排行榜和 Bot 自己对局。工具只作用于当前会话：群聊查询本群，私聊查询全局。

## 查分

- 先调用 `game_leaderboard`，不要凭记忆或上下文编造成绩。
- `scope=group` 是当前群；`scope=global` 汇总所有群。
- `period=all` 总榜，`week` 最近 7 天；`kind=human` 人类，`bot` Bot，`all` 全部。
- 返回的玩家名是掩码 QQ 或 `Bot`；不要尝试还原或猜测完整 QQ。
- 用户问“我多少分”时调用 `game_my_scores`。最高分为 0 表示该 QQ 还没有网页成绩，不要把它说成失败。
- 用户问入口时，群内可用 `/games` 获取本群链接；网页需要填写 QQ 号，属于自助申报、未验证归属。

## Bot 自己玩 2048

- 只有用户明确要求 Bot 玩时才调用 `game_2048_start`。
- 返回的 `text` 是 4x4 文本棋盘：数字是方块，`.` 是空位，`legal` 是当前合法方向。
- 每次只走一步：先看 `state`/`text`，再调用 `game_2048_move(run_id, direction)`，direction 为 `up/right/down/left`。
- 无效移动返回 `moved=false`，棋盘不变；换一个合法方向，不要重复提交同一方向。
- 游戏结束（`over=true` 或 `finished=true`）时成绩已自动保存，不要再调用保存接口，也不要自己报一个分数。
- 用户要求提前结束时调用 `game_2048_finish`。
- 对局可能很长；不要在一次回复里无限连走，按用户要求或合理步数停下来汇报当前分数和棋盘。
- Bot 成绩属于 Bot 榜，不冒充人类成绩。

## 回复

- 分数、最大块、步数只引用工具返回值。
- 排行回复简洁给前几名；用户要完整榜单时再展开。
- 不展示完整 QQ、内部 run_id、seed、cookie 或服务端错误细节。
