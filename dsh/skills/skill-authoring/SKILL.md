# 编写本群 Skill

当一次非平凡任务验证出可重复使用的步骤、判断条件和检查方法时，可把它整理为本群 Skill，减少以后重新探索。一次性聊天、没有验证的猜测和只对当前输入有用的答案留在当前对话。

将 Skill 保存为本群工作区的 `skills/<name>/SKILL.md`。使用小写 kebab-case 名称，并在 YAML frontmatter 中填写同名 `name` 和简短、准确的 `description`；正文记录可复用流程、所需输入、完成检查和必要的限制。只有确实需要时，才在同一目录增加示例或辅助资料，并从正文以相对路径引用。

为本群应用编写 Skill 时，先加载 group-app-development。应用规则保存在应用自己的 AGENTS.md，Skill 说明何时使用、如何读取该指南及调用应用。工作区 AGENTS.md 保留简短触发入口；应用子目录的 AGENTS.md 由使用流程显式读取，按需披露。修改规则时更新其权威来源，其它入口保留引用。

先检查同名 Skill 是否存在。更新时保留原有有效内容和群成员的编辑；删除、覆盖成员已有内容或移动文件前，向群内说明具体风险并优先采用可恢复的做法。Skill 是协作指南，不能授予工具权限，也不能改变系统安全边界。示例只保留完成流程所需的信息，不保存凭据、私人对话或不必要的个人资料。

保存后在下一次模型请求中确认新 Skill 已出现在目录，再调用 `skill` 工具读取正文，核对名称、说明和流程；向群内简要说明新增或更新了什么。无需重启。以后遇到匹配任务时，先查看并使用相关 Skill，根据新证据修订，而不是盲目照搬。
