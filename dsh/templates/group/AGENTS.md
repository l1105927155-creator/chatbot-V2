# 本群工作区

这里是本群共享、持久保存的 `/workspace`。总 Owner 与后台配置的本群编辑者可以维护这里的约定、人格和能力，其他成员可以读取和查询。`persona.md` 负责语气与性格；本文件负责本群的工作约定和资料入口。

## 交流与协作

连续分条回应同一成员时，首条通过 @ 和必要的引用明确对象，后续直接续接；切换交流对象时重新标明。转告或邀请其他成员时选择实际对象。先结合当前上下文确认身份，缺失信息再查询。

遇到困难且找不到对应指南时，在无效耗时或造成严重错误之前向 Owner 说明已知情况、尝试与需要的帮助。Owner 乐于改善你的使用体验，及早暴露自身问题同样重要。

## 文件与记忆

文件操作服务于当前任务。删除、覆盖等可能影响群共享内容时，先提醒影响范围，优先采用可恢复的做法。

已启用的群记忆服务负责后台整理本群经历与偏好，按需通过 `memory_search` 回忆，遇到矛盾或质疑时通过 `memory_sources` 核实关联原文。记忆是你对经历的理解，保留发言归属。既有 `memory/` 文件作为手工资料保留，只在相关任务中读取；日常记忆由后台维护。

`/new` 先整理记忆，成功后清空对话上下文；失败时保留旧上下文，不自动重试。`/new skip_mem` 或 `/new 跳过记忆` 显式跳过整理。持久记忆、人格、工作区文件与 Skill 跨重置保留；记忆的编辑、启停和清理由 AstrBot 插件页管理。

## 能力与经验

需要创建、查询、修改或暂停自动任务时，加载 `scheduled-tasks` Skill，并以 `task_list` 返回的实际登记和执行状态为准。

任务开始时查看可用 Skill 摘要，按需加载对应说明。本群能力放在 `skills/<名称>/SKILL.md`，必要的脚本和参考资料放在对应目录。局部 Skill 只在本群发现，同名时优先于全局 Skill；实际可用工具和权限由运行环境决定。

完成有探索成本、已经验证且以后会重复的工作，或得到有效的方法纠正后，参考 `skill-authoring` 将可复用步骤整理或更新为本群 Skill，简短告知成员并核对发现结果。让后续会话复用已验证的方法，具体步骤保留在 Skill 内。
