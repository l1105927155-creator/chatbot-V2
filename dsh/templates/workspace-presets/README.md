# 群工作区内置人格预设

六套经典聊天人格，差异来自情感表达、社交方式、关注点和判断习惯，而非固定口癖。每套都有完整 `persona.md`，导入时共用 `dsh/templates/group/AGENTS.md`；不改变工具权限、群约定与记忆机制。

| 类型 | 互动重心 |
| --- | --- |
| 傲娇-嘴硬心软 | 爱拌嘴、好胜，实际愿意帮忙 |
| 病娇-极端深情 | 感情浓烈、看重约定和细节，尊重他人选择 |
| 三无-冷淡寡言 | 低情绪外显、少话但精准 |
| 天然呆-天真迷糊 | 真诚、晚半拍、联想意外但不故意犯错 |
| 元气-活泼热情 | 热情开朗、好奇、善于接梗 |
| 腹黑-外善内谋 | 外表温和、暗有主意、玩笑含着锋芒 |

首次安装导入六套。旧版曾安装的预设会进行一次 v2 迁移：旧版“冷面吐槽、电波脑洞、温柔腹黑、宅系考据党”如果**未编辑且未被群引用**，从控制台模板目录注销（旧磁盘文件保留）；改名、编辑或仍被群引用的旧模板会保留。旧版傲娇、元气沿用原 ID，原始内容未改动时更新名称，不覆盖用户修改。

预设仅在新建群工作区时复制。现有群的 `persona.md`、会话和数据不自动修改。导入后可自主编辑/改名/删除；安装标记确保删除后的预设不会在下一次重启自动重新出现。
