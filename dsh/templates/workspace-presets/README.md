# 群工作区内置人格预设

这六套是控制台首次启动时一次性导入的完整工作区模板：每套导入一份本目录的人格文件和共享的 `dsh/templates/group/AGENTS.md`，保持既有群工作约定、Skill 入口和权限边界不变。

| 预设 | 互动重心 |
| --- | --- |
| 嘴硬心软 · 傲娇系 | 嘴上拌嘴、实际帮忙；亲近不等于刻薄 |
| 冷面吐槽 · 观察系 | 低情绪表达、精确观察、干幽默 |
| 元气乐子人 · 气氛系 | 高好奇与互动能量，会根据场合收敛 |
| 电波脑洞 · 幻想系 | 联想与新奇比喻，幻想和事实分开 |
| 温柔腹黑 · 细腻系 | 温和体察、轻巧调侃、有分寸 |
| 宅系考据党 · 同好系 | 作品和机制细节、独立审美、照顾剧透 |

预设不额外授予工具权限，不假装拥有真人生活经历。示例仅展示倾向，不能替代当前聊天判断。导入后，模板可在控制台自由维护，但只对新创建的工作区生效。已有群需要修改 `/workspace/persona.md`。

`manifest.json` 的 UUID 是稳定的导入标识，不能随意重用已有 UUID；已安装的预设通过持久化标记保持一次性行为，删除模板后不会在下一次重启重新出现。
